# DMA driver: file overview

The STM32H7 DMA driver for DMA1, DMA2 and DMAMUX1. It uses Intel's groov
for register access, on maps generated from the SVD (`stm32h7::regs::dma`,
`dmamux1`), and supports interrupts. This page lists every file the driver
consists of and what each one does.

## Dependency graph

```
                     user code
                         |
         +---------------+-----------------+
         v                                 v
  dma/stream.h                     dma/tx_completion.h ---> tx_api.h (ThreadX)
   |  extern template x16                  |
   |                                       v
   +--> dma/buffer.h                 dma/types.h
   +--> dma/types.h
   +--> dma/detail/stream_traits.h
          +--> stm32h7/irq.h, stm32h7/regs/dma.h (groov map)

  generated dmaX_streamN.cc (one per stream, built with -O2)
   +--> dma/detail/stream_impl.h
          +--> dma/stream.h
          +--> dma/dmamux.h --> stm32h7/regs/dmamux1.h
          +--> hal/cortex_m.h  (NVIC), stm32h7/regs/rcc.h
          +--> groov/groov.hpp
```

No CMSIS or ST HAL header is involved: the registers, IRQ numbers and RCC
bits come from the generated maps (`docs/architecture.puml`).

User code includes only `dma/stream.h` and, if needed, `dma/tx_completion.h`.
The groov code (`stream_impl.h`, `dmamux.h`) is compiled only in the
generated per-stream translation units, with -O2, so only the streams in
use (and their IRQ handlers) are linked.

## Public API (`include/dma/`)

| File | Purpose |
|---|---|
| `stream.h` | `dma::Stream<Controller, N>`: the stream API (`Init`, `SetCallback`, `Configure`, `Start`, `Stop`, `IsBusy`, `Remaining`, `HandleIrq`). All static, one instantiation per hardware stream. Contains only declarations, plus `extern template` for all 16 streams, so including it is cheap. |
| `types.h` | Vocabulary types: `Controller`, `Direction`, `DataSize`, `Priority`, `Mode`, `Fifo`, `Request` (DMAMUX1 request IDs), `Event` bitmask and its operators, `kErrorEvents`, `Error`, `Config`, `Callback` (function pointer + `void* context`). Enumerator values are the hardware encodings. |
| `buffer.h` | `DMA_BUFFER` attribute, which places buffers in the `.dma_buffer` section (non-cacheable D2 SRAM1). `IsDmaReachable()` rejects ITCM/DTCM addresses; `Start()` uses it. |
| `tx_completion.h` | `dma::TxCompletion`: ThreadX adapter. Provides a `Callback` that sets event flags from the ISR, and `Wait(timeout)`, which blocks a thread until an event arrives. Keeps the driver core RTOS-agnostic. |
| `dmamux.h` | `dma::dmamux1::Route<Channel>(Request)`: routes a DMAMUX1 channel to a peripheral request, with synchronization and event generation off. Internal; used by `Configure()`. |

## Internals (`include/dma/detail/`)

| File | Purpose |
|---|---|
| `stream_traits.h` | `StreamTraits<C, N>`: compile-time description of one stream. Holds its groov group (`regs::dma::kDma1`/`kDma2`); register and field names built with `hal::detail::Name` (`"s3cr"`, `"lisr"`/`"hisr"`, `"tcif3"`, `"ctcif3"`, ...); DMAMUX channel (`C*8 + N`); `stm32h7::Irq`; RCC clock-enable field (`"dma1en"`). |
| `stream_impl.h` | Definitions of all `Stream` member functions, with the groov paths (`Paths<C, N>`) and config validation (`IsValid`). Included only by the generated per-stream sources. The interrupt-path members are `[[gnu::flatten]]` (declared in `stream.h`), so groov's wait is inlined too. |

## Register maps (`include/stm32h7/regs/`)

`dma.h` (DMA1/DMA2) and `dmamux1.h` are groov maps generated by
`tools/svd2groov`; do not edit them. `tools/svd2groov/stm32h7.toml` corrects
the SVD:

| Register | Correction of the SVD |
|---|---|
| `LIFCR`, `HIFCR` | Write 1 to clear (`write_only<w::one_to_set>`), so clearing is a single store. |
| `SxFCR.FS` | Read-only. |
| `SxCR.TRBUFF` (bit 20) | Missing in S0CR, named ACK in S1CR..S7CR. |

## Hardware abstraction helpers (`include/hal/`)

| File | Purpose |
|---|---|
| `word_mmio_bus.h` | `hal::WordMmioBus`: the groov bus of the generated maps, always 32-bit accesses. DMA/DMAMUX registers are word-access only (RM0399); groov's `mmio_bus` would narrow writes to byte/halfword stores. It skips the read when the write covers every bit. |
| `concurrency_policy.h` | `hal::InterruptLockPolicy`: injected as `conc::injected_policy<>`. Gives groov's freestanding dependencies a critical section (`hal::cortex_m::InterruptLock`: save PRIMASK, disable interrupts, restore). Nestable and ISR-safe. |
| `cortex_m_cpu.h` | `hal::cortex_m`: the special registers (PRIMASK, FAULTMASK: `mrs`/`msr`), `Dsb()`/`Isb()` and `InterruptLock`, inline asm (CPU instructions, not memory-mapped registers). |
| `cortex_m.h` | `hal::cortex_m`: NVIC `SetPriority<Irq>()` (with the current priority grouping, like `NVIC_EncodePriority()`), `EnableIrq<Irq>()`, `SetPendingIrq<Irq>()`, `SetBusFaultIgnore()`, `InvalidateDCache()`, with groov on the core maps (`nvic`, `nvic_ipr`, `scb`), in place of CMSIS-Core. Driver-internal (groov). |
| `detail/ct_name.h` | `hal::detail::Name<"s", 3, "cr">()`: compile-time names of numbered registers and fields for groov paths. |
| `rcc.h` | The bus clocks `HclkHz()`/`Pclk1Hz()`/`Pclk2Hz()` from `SystemCoreClock` and the RCC prescalers. |

## Sources and build (`source/dma/`, `cmake/`)

| File | Purpose |
|---|---|
| `cmake/stm32h7_drivers/stream_instance.cc.in` | Template for one generated translation unit per stream. Each one holds the explicit instantiation `template class dma::Stream<...>;` and the matching `extern "C" DMAx_StreamN_IRQHandler()`. |
| `cmake/stm32h7_drivers/dma_streams.cmake` | One target per stream, `STM32H7Drivers::DMA::<1\|2>::<0..7>`: the generated source (`build/stm32h7_drivers/generated_dma/`) built with `groov_add_optimized_objects()` as an object library that is only compiled when linked. `target_add_dma_streams()` adds the streams in the cache variable `DMA_STREAMS` (e.g. `"1.0;1.1"`; default all 16) instead. |
| `source/dma/tx_completion.cc` | `TxCompletion` implementation: `tx_event_flags_create/get/set/delete`. Error events map to `Error::kTransferError`. |
| `cmake/FindGroov.cmake` | Adds groov (`GROOV_PATH`, default the `external/groov` submodule) and the `groov_baremetal` / `Groov::Baremetal` interface target (groov plus `STDX_FREESTANDING`, `CONC_FREESTANDING`, `ASYNC_FREESTANDING`). |
| `cmake/stm32h7_drivers/groov_baremetal.cmake` | Shared with the USART driver: the `GROOV_COMPILE_JOBS` Ninja pool (default 4); `groov_add_optimized_objects()`, which builds groov TUs with `-O2` in every configuration. |
| `source/dma/stream_traits_check.cc` | `static_assert`s on `StreamTraits` against RM0399: IRQ numbers (NVIC vector table), DMAMUX channels, LISR/HISR split, generated register names, base addresses. No runtime code. |

Generated at configure time (not in git): `<build>/generated_dma/dma<1|2>_stream<0-7>.cc`.

## Required outside these files

- **CubeMX:** DMA must stay disabled in the `.ioc` for every request the
  driver serves. The generated stream sources define the
  `DMAx_StreamN_IRQHandler`s, so the CubeMX copies in `stm32h7xx_it.c` would
  cause duplicate symbols.
- **Linker script:** a `.dma_buffer (NOLOAD)` output section for `DMA_BUFFER`,
  in RAM that DMA1/DMA2 reach (not DTCM/ITCM), non-cacheable through the MPU
  or kept coherent by the application; the stm32_webserver firmware puts it
  in D2 SRAM1 at 0x30008000.
- **U(S)ART streams:** set `Config::bufferable = true`, and enable the
  peripheral's DMA request (`USARTx->CR3.DMAT` / `DMAR`). The driver does not
  touch peripheral registers.
